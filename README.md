# Sistema de Gestión de Préstamos

Aplicación web para administrar y dar seguimiento a préstamos personales, con cálculo de cuotas e intereses.

## Características

- Creación y edición de préstamos
- Cálculo automático de cuotas mensuales
- Generación de tablas de amortización
- Validación de formularios con Zod
- Interfaz de usuario moderna con Shadcn UI

## Tecnologías utilizadas

- Next.js
- React
- TypeScript
- TailwindCSS
- React Hook Form
- Zod
- Shadcn UI

## Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build
```
